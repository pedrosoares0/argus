# 🩺 Argus

Argus é uma plataforma web voltada para a prontidão operacional e gestão de centros cirúrgicos hospitalares. O sistema auxilia na realização de checklists de equipamentos e salas, registro e encaminhamento automático de não conformidades para setores responsáveis, além de fornecer controle e governança operacional para a equipe hospitalar.
